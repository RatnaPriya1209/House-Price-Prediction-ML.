# House Price Prediction

A Machine Learning project that predicts housing prices using the Boston Housing dataset and Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Project Workflow
1. Data Loading
2. Data Preprocessing
3. Train-Test Split
4. Model Training
5. Prediction

## Objective
To learn the fundamentals of Machine Learning and data analysis using Python.
